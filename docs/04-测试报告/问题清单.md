## 二、详细问题说明

### ISSUE-001: Locale类型定义重复

| 属性 | 内容 |
|-----|------|
| **问题ID** | ISSUE-001 |
| **严重程度** | Low (低) |
| **问题类型** | Code Quality (代码质量) |
| **状态** | 🔴 Open |
| **发现位置** | `src/locales/index.ts` 和 `src/stores/configStore.ts` |

**问题描述：**
Locale类型在两个文件中重复定义：
1. `src/locales/index.ts` 第5行：`export type Locale = 'zh-CN' | 'vi-VN';`
2. `src/stores/configStore.ts` 第7行：`export type Locale = 'zh-CN' | 'vi-VN';`

**影响范围：**
- 代码重复，维护困难
- 可能导致类型不一致

**建议解决方案：**
统一到 `src/locales/index.ts` 中定义和导出，移除 `configStore.ts` 中的重复定义，并在 `configStore.ts` 中从 `locales` 模块导入。

**参考代码：**
```typescript
// src/locales/index.ts
export type Locale = 'zh-CN' | 'vi-VN';

// src/stores/configStore.ts
import type { Locale } from '@/locales'; // 移除本地定义
```

**优先级：** P3 (低)  
**预计工时：** 0.5小时
